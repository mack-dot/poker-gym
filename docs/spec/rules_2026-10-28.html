3. POKERBOT COMPETITION FORMAT

3.1These competition rules apply to both the regionals and the Finals.
3.2The poker variant will be revealed on the day of each event at the start of the build phase. It will remain confidential until that announcement.
3.3Teams have 60 minutes to build a Python bot that implements the provided Agent interface. Teams receive a starter kit containing an agent template, local simulator, Independent Chip Model (ICM) calculator, payout structure, and blind schedule.
3.4Teams may use Astra and Codex to write, debug, and refine their bots during the build phase. Publicly available documentation is permitted.
3.5Each team may submit one bot every five minutes. The team's most recently accepted submission becomes its active bot.
3.6Submitted bots run in isolated sandboxes without network access. They cannot call OpenAI tools, external APIs, or any other outside service to make gameplay decisions.
3.7Each bot must return a decision within one millisecond. The maximum file size is 100mb. If a bot encounters an error or exceeds the time limit, it automatically folds, or checks if checking is available.
3.8Bot state resets at the start of each table. Opponents are anonymized so bots cannot identify specific teams.
3.9Bots compete exclusively against other bots. No humans play in the bot competition. Chips and points exist only within the simulation and have no cash value.
3.10No real money is bet by the bots. Participants, spectators, hosts, and all other attendees may not bet or wager on competition outcomes.

4. SCORING

4.1There are six scored tournaments, labeled T1-T6. The first begins at the end of the 60-minute build phase, with subsequent tournaments starting 20 minutes apart.
4.2Teams may continue editing and submitting bots after the build phase. At the start of each scored tournament, each team's active bot is frozen for that tournament. Any submissions accepted afterward apply to the next scored tournament.
4.3Each scored tournament consists of 10,000 simulated eight-bot sit-and-gos. In each iteration, bots are randomly assigned to tables.
4.4Each table plays until one bot holds all the chips or 200 hands have been played. Each bot starts with 2,000 chips. Blinds start at 10/20 and increase every 25 hands.
4.5Points are awarded based on each bot's finishing position at its table. The point distribution may vary by poker variant and will be announced at the start of the build phase. An eliminated bot receives the points assigned to its finishing position. If a table reaches the 200-hand limit, the remaining points are allocated among the surviving bots using the Independent Chip Model (ICM).
4.6If the number of competing bots is not divisible by eight, empty seats are filled with randomly selected copies of submitted bots. These filler bots earn no points.
4.7A team's score for each scored tournament is its average points per table across the 10,000 iterations. Later tournaments carry greater weight: Final score = (T1 score × 1) + (T2 score × 2) + (T3 score × 3) + (T4 score × 4) + (T5 score × 5) + (T6 score × 6).
4.8Ties are resolved by a tie-breaker challenge to be determined by the Organizer. The Organizer will announce the tie-breaker challenge and its objective skill-based scoring criteria.
4.9Competition rankings and prizes depend solely on bot performance under this scoring system, subject to the tie-breaking rule.
